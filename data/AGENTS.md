# AGENTS.md "Data"

- [README.md](README.md) defines the format here.
- Copy passages into a source's blockquotes word for word. Never write a
  quote or URL from memory; copy it from the source you have open.
- Cite only passages that already sit in a source's blockquotes.
- A life event is one moment, in the source's own words: an excerpt of a
  captured passage. A passage that tells several moments becomes several
  life events.
- New item IDs come from `tools/newid.py`, once `published/` has no item
  for the same thing. Never reuse or hand-pick one.
- Run `tools/validate.py` before committing. Nothing that fails it is data.
- `examples/` is fictional. Never copy anything from it into `capture/` or
  `published/`.
